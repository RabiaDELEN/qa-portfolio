# SauceDemo Manuel Test Çalışması

saucedemo.com üzerinde yaptığım manuel test çalışması.

## İçerik
- Test senaryoları: giriş ve sepet akışları (test-senaryolari.xlsx)
- Hata raporları: problem_user ile bulunan iki hata
  1. Ürün listesinde "Remove" butonu ürünü sepetten çıkarmıyor
  2. Bazı ürünlerde "Add to cart" butonu çalışmıyor

## Kullanılan araçlar
Jira (hata takibi), Google Sheets (test senaryoları), Safari DevTools / ekran kaydı
