# Postman API Testleri

jsonplaceholder.typicode.com üzerinde yazdığım API testleri.

## İçerik
- GET /posts/1: status 200 ve id doğrulaması
- GET /posts/99999: olmayan kayıt için 404 (negatif test)
- POST /posts: status 201 ve title doğrulaması

## Nasıl çalıştırılır
1. Postman'e `.json` dosyasını Import et
2. Collection'ın yanındaki Run'a bas
